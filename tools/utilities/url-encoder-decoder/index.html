💡 What is URL Encoding? The URL specification (RFC 3986) only permits a limited set of ASCII characters in a web address. Characters outside this set — such as spaces, punctuation marks, non-Latin scripts like Hindi or Chinese, and symbols like & ? = # @ — must be converted into a percent-encoded representation before being placed in a URL. The conversion works by taking each byte of the character's UTF-8 representation and writing it as %XX, where XX is the byte's value in hexadecimal. For example, the word राहुल becomes %E0%A4%B0%E0%A4%BE%E0%A4%B9%E0%A5%81%E0%A4%B2. This encoding is what makes it possible to share links containing names, search queries, and content in any language around the world. All processing on this tool happens locally inside your browser.
