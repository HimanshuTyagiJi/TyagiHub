Internet की तीन परतें

🌑 Dark Web क्या होता है? — सरल भाषा में

Internet के 3 हिस्से होते हैं:

हिस्साक्या हैExample
Surface Webजो Google पर search होता हैYouTube, Facebook, News sites
Deep Webजो search में नहीं आता — login requiredआपकी Gmail, Bank account, Hospital records
Dark WebSpecial browser (Tor) से accessible — anonymous, untrackedStolen data markets, illegal activities

Dark Web पर — चोरी हुए passwords, credit card numbers, Aadhar data, email lists — यह सब खुलेआम बिकता है। India में हर साल करोड़ों लोगों का data किसी न किसी company से leak होता है। Bigbasket, Mobikwik, Unacademy, AIIMS Delhi — इन सबका data Dark Web पर बिक चुका है।

⚠️
Dark Web पर खुद कभी मत जाओ — यह कारण हैं: Tor browser install करते ही — आपका IP suspicious list में आ जाता है। Dark Web की 70% sites fake हैं — आते ही malware download हो जाता है। India में Tor browser use करना technically legal है — लेकिन इससे जो sites खुलती हैं उनसे interaction — illegal। एक गलत click — और आपका पूरा device compromise।
