📐 Algebra (बीजगणित)

Polynomial Definition (बहुपद)

$$ P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 $$

A mathematical expression consisting of variables and coefficients.

Quadratic Polynomial (दो-घात बहुपद)

$$ P(x) = ax^2 + bx + c \quad (a \neq 0) $$

A polynomial of degree two, forming a parabola when graphed.

📈 Calculus & Functions

One-to-One Function (एकैकी फलन)

$$ f(x_1) = f(x_2) \implies x_1 = x_2 $$

A function that maps distinct domain elements to distinct codomain elements.

Class 12

Bijective Function (एकैकी आच्छादक फलन)

$$ f: A \to B \text{ is bijective } \iff f \text{ is injective and surjective} $$

A function that is both injective (one-to-one) and surjective (onto).
