ICONS FOLDER
============
Place custom SVG icon files here.
Naming: icon-[name].svg  (e.g. icon-tools.svg, icon-learn.svg)

Current status: Using inline SVG + emoji in Phase 1.
Add custom icons here as the platform grows.

Recommended free icon sets to download locally:
- Heroicons: https://heroicons.com (MIT license)
- Phosphor Icons: https://phosphoricons.com (MIT license)
- Lucide: https://lucide.dev (ISC license)

Always download SVG files — never link to CDN.
